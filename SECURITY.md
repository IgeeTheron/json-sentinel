# Security Policy

## Supported versions

Only the latest minor release on `main` receives security fixes.

| Version | Supported |
|---------|-----------|
| 0.4.x   | ✅        |
| < 0.4   | ❌        |

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature rather than opening a public issue:

**[Report a vulnerability](https://github.com/IgeeTheron/json-sentinel/security/advisories/new)**

Or navigate to: **Settings → Security → Advisories → Report a vulnerability**

### What to include

- `json_sentinel` version affected
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We aim to acknowledge reports within **5 business days** and will keep you informed of progress throughout the process.
